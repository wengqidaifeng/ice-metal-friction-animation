# 冰-金属摩擦实验控制台

这是配套 `esp32_ice_friction_slider` 固件的本地 Web 串口调试软件。它通过浏览器 Web Serial API 连接 ESP32-S3，适配 115200 baud、8N1 和当前固件协议。

## 启动

在本目录打开 PowerShell，运行：

```powershell
py -m http.server 8765
```

然后用最新版 Microsoft Edge 或 Google Chrome 打开：

`http://127.0.0.1:8765`

Web Serial 要求在 `localhost` 或 `127.0.0.1` 页面中由用户点击按钮选择串口。首次连接时选择 ESP32 使用的 CH343 端口（目前为 COM12），波特率保持 115200。

## 推荐操作顺序

1. 确认丝杆滑台没有障碍物，电机电源与 ESP32 共地，实体急停可用。
2. 先点击“连接串口”，观察日志中的 `ICE_FRICTION_SLIDER,READY` 和 `STATUS`。
3. 金属块不受拉力时点击“TARE 去皮”；如已经完成标定，确认“已标定”状态。
4. 输入金属块质量。软件用 `μ = F_t / (m g)` 计算瞬时摩擦系数，质量不参与电机控制。
5. 未安装 HOME/FAR 限位开关前，不要点击“HOME 回零”，不要进行无人看守的长距离运行。
6. 低速实验可设置 `0.2 mm/s`、行程 `20 mm`，先点“开始记录”，再点击“按行程运行”。
7. 运行结束点击“停止记录”，用“导出 CSV”保存数据。

串口日志下方保留了原始命令输入栏，可直接发送 `STATUS`、`HELP` 或固件后续新增的调试命令。收到 `STATUS` 后，界面会自动同步固件当前的目标速度、行程、加速度和 `steps/mm`。

## 重要说明

- 软件急停只是发送 `ESTOP` 串口指令，不替代硬件急停。出现卡滞时，优先切断电机电源或按实体急停。
- 当前固件的 HX711 标定值保存在 RAM，ESP32 重启后需要重新 TARE/CAL。
- 曲线中的橙色拉力点代表固件 `steady=1` 的匀速段；`μ_k` 是这些点的平均值，`μ_s` 是当前采样窗口内的拉力峰值换算值。
- 没有接好 HX711 时，真实数据的 `force_N` 为 `nan`，此时 μ 显示为 `--`，不影响先调试滑台。
- “模拟数据”只在浏览器中生成数据，绝不会发送运动指令，可用于没有接硬件时检查曲线、记录和 CSV 功能。
