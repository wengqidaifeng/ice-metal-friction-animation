# 冰-金属摩擦实验控制台

这是配套 `esp32_ice_friction_slider` 固件的控制台。浏览器版使用 Web Serial API，Electron 桌面版使用原生 `serialport` 通道，均适配 115200 baud、8N1 和当前固件协议。当前固件还支持 ESP32 Wi-Fi API，桌面版可在顶部切换 USB 串口和 Wi-Fi。

## 启动

在本目录打开 PowerShell，运行：

```powershell
py -m http.server 8765
```

然后用最新版 Microsoft Edge 或 Google Chrome 打开：

`http://127.0.0.1:8765`

Web Serial 要求在 `localhost` 或 `127.0.0.1` 页面中由用户点击按钮选择串口。首次连接时选择 ESP32 使用的 CH343 端口（目前为 COM12），波特率保持 115200。

## 推荐操作顺序

1. 确认丝杆滑台没有障碍物，电机电源与 ESP32 共地，实体急停可用。
2. 先点击“连接串口”，观察日志中的 `ICE_FRICTION_SLIDER,READY` 和 `STATUS`。
3. 金属块不受拉力时点击“TARE 去皮”；如已经完成标定，确认“已标定”状态。
4. 输入金属块质量。软件用 `μ = F_t / (m g)` 计算瞬时摩擦系数，质量不参与电机控制。
5. 未安装 HOME/FAR 限位开关前，不要点击“HOME 回零”，不要进行无人看守的长距离运行。
6. 低速实验可设置 `0.2 mm/s`、行程 `20 mm`，选择“正向”或“反向”，先点“开始记录”，再点击对应方向的运行按钮。
7. 运行结束点击“停止记录”，用“导出 CSV”保存数据。

串口日志下方保留了原始命令输入栏，可直接发送 `STATUS`、`HELP` 或固件后续新增的调试命令。收到 `STATUS` 后，界面会自动同步固件当前的目标速度、行程、加速度和 `steps/mm`。

方向选择保存在控制台中。按行程运行时，正向会发送 `JOG 20`，反向会发送 `JOG -20`；界面会在发送前显示实际命令。固件的 `DIST` 参数仍只保存正数行程，不能使用 `DIST -20` 设置方向。

## 拉力传感器调试

传感器工作区按当前 `S 型传感器 → HX711 → ESP32` 链路设计，不包含固件不支持的 Modbus 地址、写保护等设置。

- 两步标定：空载时发送 `TARE`，加载已知质量后发送 `CAL <grams>`；软件显示固件返回的 `scale_raw_per_N` 和已知载荷。
- 信号处理：可选择 N、gf、kgf，使用原始值、滑动平均或中值滤波，设置滤波点数和统计窗口。
- 诊断量：同时显示 ESP32 原始力、处理后力值、窗口均值、标准差、峰峰值、最小值、最大值、采样率和稳定状态。
- 本地工具：支持单次抓取、冻结显示、本地置零、清空统计和可选过载阈值。本地置零不会改变 ESP32 的标定参数。
- 数据追溯：CSV 中的 `force_N` 始终保存 ESP32 原始物理力值，`processed_force_N` 保存经过符号、本地零点和滤波后的上位机值，同时记录滤波配置与稳定性结果。

上位机处理参数保存在本机。硬件标定值仍由当前固件保存在 RAM，ESP32 重新上电后应重新执行 TARE/CAL。

## 重要说明

- 软件急停只是发送 `ESTOP` 串口指令，不替代硬件急停。出现卡滞时，优先切断电机电源或按实体急停。
- 当前固件的 HX711 标定值保存在 RAM，ESP32 重启后需要重新 TARE/CAL。
- 曲线中的橙色拉力点代表固件 `steady=1` 的匀速段；`μ_k` 是这些点的平均值，`μ_s` 是当前采样窗口内的拉力峰值换算值。
- 没有接好 HX711 时，真实数据的 `force_N` 为 `nan`，此时 μ 显示为 `--`，不影响先调试滑台。
- “模拟数据”只在浏览器中生成数据，绝不会发送运动指令，可用于没有接硬件时检查曲线、记录和 CSV 功能。
