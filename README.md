# 冰与金属摩擦系数测量装置三维动画

这是物理实验设计竞赛项目的交互式三维演示页面，包含开放式保温槽、冰面、金属滑块、TEC 制冷片、散热器、风扇、牵引与测力机构，以及 ESP32 控制模块。

打开 GitHub Pages 链接后，可以旋转、缩放、暂停运动、切换剖视和制冷层爆炸图。

## ESP32 丝杆滑台实验控制台

仓库的 `slider-console` 目录包含冰-金属摩擦实验专用串口控制界面，可设置滑台速度、行程和加速度，执行点动、运行、停止、回零与软件急停，并实时显示位置、速度、拉力和摩擦系数曲线。实验数据可记录并导出 CSV。

`desktop` 目录和根目录的 `package.json` 提供 Electron 桌面封装。桌面版以独立 Windows 窗口运行，不需要手动打开浏览器。构建与安全说明见 [DESKTOP_APP.md](DESKTOP_APP.md)。
